## ៤. ស្លាកសញ្ញា និងម៉ាក

**PyTorch**, រូបសញ្ញា PyTorch និងឈ្មោះ API (`torch`, `torch.nn`, `torch.optim`,
`Tensor`, `backward()`, `requires_grad`, `DataLoader` ។ល។) គឺជាស្លាកសញ្ញា
ឬម៉ាកពាណិជ្ជកម្មរបស់ **PyTorch Foundation** ឬម្ចាស់រៀងៗខ្លួន។

គម្រោងនេះប្រើឈ្មោះទាំងនោះក្នុងគោលបំណង **ពិពណ៌នាបច្ចេកទេស** តែប៉ុណ្ណោះ
(nominative use)។ គម្រោងនេះមិនមានទំនាក់ទំនងផ្លូវការជាមួយ PyTorch Foundation ឡើយ។

ឈ្មោះ API ទាំងអស់ត្រូវបាន **រក្សាទុកជាភាសាអង់គ្លេសដូចដើម** ដោយមិនបានបកប្រ —
នេះជាទាំងការគោរពច្បាប់ស្លាកសញ្ញា និងតម្រូវការបច្ចេកទេស
(ព្រោះអ្នកអានត្រូវ copy ពួកវាចូលក្នុងកូដ)។
