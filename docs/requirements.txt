# Sphinx build dependencies for Read the Docs.
#
# NOTE: PyTorch and NumPy are deliberately NOT listed here.
# They are only required to *execute* the code examples (tests/run_examples.py),
# never to render them. Excluding them keeps the Read the Docs build small
# (the CPU PyTorch wheel alone is ~200 MB) and fast.
#
# To run the examples locally, install PyTorch separately, e.g. CPU-only:
#     pip install torch --index-url https://download.pytorch.org/whl/cpu
#     pip install numpy

# Versions below are the ones the site is actually tested against; the upper
# bounds keep Read the Docs from resolving something newer and untested.
# Verified combination: Sphinx 7.4.7 + sphinx-rtd-theme 3.1.0 + myst-parser
# 4.0.1 + docutils 0.21.2 on Python 3.11 (local) and 3.12 (Read the Docs).
#
# Constraints are mutually compatible: sphinx-rtd-theme needs sphinx<10,>=6 and
# docutils<0.23,>0.18; myst-parser needs sphinx>=7,<9 and docutils>=0.19,<0.22.
sphinx>=7.4,<8.0
sphinx-rtd-theme>=3.0,<4.0
myst-parser>=4.0,<5.0
docutils>=0.20,<0.22
